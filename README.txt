ODP CONSULTING - SITE STATIQUE

1) Ouvrez config.js et renseignez :
   - bookingsUrl : votre lien public Microsoft Bookings
   - contactEmail : votre e-mail professionnel
   - phone : votre numéro au format international (+33...)
   - whatsapp : votre lien WhatsApp complet si souhaité

2) Le site contient 4 pages :
   - index.html
   - expertises.html
   - france-maroc.html
   - conseils.html

3) Domaine : odp-consulting.com
   Vous pouvez conserver le domaine chez OVH et faire pointer les DNS vers un hébergement gratuit (par exemple GitHub Pages).

4) Identité : vert #2c9f1c, police Lato, logo dans assets/logo.png.
